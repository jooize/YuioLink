YuioLink · design note 7

Scheme text colour, without icons

Copy fixed: "Hands this to a torrent app" was wrong. A magnet URI names a resource by cryptographic hash rather than by location — BitTorrent is its most common consumer, not its definition. The lid now says "Hands this to another app", which is true whatever is registered for the scheme.

Icons dropped, so the scheme word is now the entire identity of the destination — which makes its colour the question below. Section 4 has the magnet glyph you asked for, parked rather than shipped.

1 · Six treatments

One thing worth having in hand first: for a hostless URL, card_domain() already falls back to the scheme. The scheme is this link's domain — the one string that says where you are going. So the strongest candidates are the ones that give it the same treatment .pv-url .reg gives a real domain.

A

Amber text

As built in round 5
mailto: hello@example.com
tel: +47 800 12 345
magnet: ?xt=urn:btih:c12fe3…9ab4

Ties the plate to the amber button below it. Against: amber is the colour of the control here — of pressing and leaving. Spending it on a static string means the page has two amber objects and only one of them does anything.

B · Pick

Dark text, accent highlight

Identical to .pv-url .reg
mailto: hello@example.com
tel: +47 800 12 345
magnet: ?xt=urn:btih:c12fe3…9ab4

The same object as a highlighted domain, because it plays the same part. A visitor who has seen one preview reads this one for free. Note this does not break the colour rule: the accent tint marks the part that matters in a block of text — it is already used this way behind example.com on links that take you away. Only buttons carry the where-do-I-end-up meaning.

C

Dark text, amber highlight

Same construction, tier colour
mailto: hello@example.com
tel: +47 800 12 345
magnet: ?xt=urn:btih:c12fe3…9ab4

Keeps full legibility and still marks the tier. Against: it says "this scheme is the warning", when what deserves marking is the same thing as on any other preview — where you are going. The lid is already the tier's voice.

D

Plain text

No colour, no highlight
mailto: hello@example.com
tel: +47 800 12 345
magnet: ?xt=urn:btih:c12fe3…9ab4

Calm and completely legible. Against: with icons gone this is the only distinguishing mark a non-web destination has, and plain 24px mono is what the whole page is set in. Nothing says "this one is different in kind".

E

Amber on amber

Text and highlight both
mailto: hello@example.com
tel: +47 800 12 345
magnet: ?xt=urn:btih:c12fe3…9ab4

Fails contrast before it fails taste: amber text on an amber wash is the one combination in this set that cannot reach 4.5:1 at any tint that still reads as amber. mailto: does not warrant the loudest object on the page either.

F

Dim scheme, loud body

Inverts which half matters
mailto: hello@example.com
tel: +47 800 12 345
magnet: ?xt=urn:btih:c12fe3…9ab4

Arguably the honest emphasis for mailto: and tel: — the address and the number are what a person checks. Against: it collapses for magnet:, whose body is an unreadable hash, and it hides the one word that says which kind of app is about to open.
