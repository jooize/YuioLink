Hidden characters in the form, before the link is made

Each frame is a live copy of the form: type or paste in its field. The check runs on every edit, in the browser, with the same character list the server marks after creation (zero-width, direction-changing, odd spaces, controls; tabs and line breaks are layout). A variation selector counts only when it follows another one, since the browser cannot tell a registered pair (❤️, a keycap #️⃣) from an odd one; the link's page still marks the rest. Remove Them deletes each character, except that a space-like one becomes a plain space and a line or paragraph separator becomes a line break. Without JavaScript nothing shows here, and the result page marks them as it does today.
