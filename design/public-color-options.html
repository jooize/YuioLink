Public type color — options

Six candidates for --c-public, each in the shipped picker with Public selected and the disclosure open, light and dark. Everything the token tints moves with it: the dot before "Public", the bold lead of the summary line, the details-body left border and its 8% wash, and the "Browse the wordlist →" link. The grey "Not secret!" tail and the blue "Security" toggle never follow the type color — that is the point of comparison, since Public's blue currently collides with that toggle.

The text this color carries is 12px bold, so AA wants 4.5:1 against the glass. Contrast figures are in the table at the bottom.

1 · Blue — shipped now #0a6cd6 / #5aa9ff

Contrast is good and it reads calm, but it sits a few degrees from --accent #007aff, which colors the "Security" toggle on the same line and the Create Link button right above. Public ends up looking like "the app color" rather than a type key.

2 · Amber — the straight revert #c9820f / #ffd400

3 · Gold — amber taken down to AA #8f5a00 / #ffc93c

The same warm family, deepened until the light value clears 4.5:1. Reads as gold/bronze rather than caution yellow — the hue keeps its "open, daylight" feel without the traffic-light connotation. Note the cost: on a light background, a true yellow can never be AA for small text, so this is as yellow as light mode gets.

3b · Split — amber dot, gold text dot #b87400, text #8f5a00 / #ffd400

The contrast rule that kills amber applies to text. The dot and the body's left border are graphical objects, where AA asks 3:1, so they can stay amber — #b87400, a touch deeper than the old #c9820f, which at 2.8:1 missed even that looser bar — while only the bold lead deepens to gold. Light mode gets a genuinely amber key and legible copy; dark mode needs no split at all, since #ffd400 clears both thresholds. Cost is one extra token in app.css and a rule that has to be explained to whoever touches it next.

4 · Orange — warm with more voltage #b34700 / #ff9f0a

Where the color actually lands

Worth keeping in mind while choosing: the type color is an 8px dot, a 2px left border, an 8% wash, and one bold 12px line. It is a key, not the page's first impression — the glass window, the blue and pink glow behind it, and the purple-bordered input are what a visitor sees first, and none of them move with this token. A colour that is "boring" at 8px is mostly invisible; a colour that is loud at 8px is a badge.
